# HTML Practice

This repository contains my HTML practice and exercises from basic to advanced concepts.

## Topics Covered

- HTML Structure
- Headings & Paragraphs
- Links & Images
- Audio & Video
- HTML Attributes
- Semantic HTML
- Navigation
- Lists
- Tables
- Forms
- Input Types
- iFrames

## Folder Structure

- `assets/` → Media files
- `images/` → Images
- `form/` → Form practice
- `.html` files → Individual HTML practice

## Goal

To build a strong foundation in HTML before moving to CSS and JavaScript.
